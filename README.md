# 🌱 Workshop Spring Boot 3 + JPA

API REST desenvolvida com Spring Boot 3 para estudo de persistência de dados utilizando Spring Data JPA e Hibernate.

O projeto simula um sistema de pedidos com clientes, produtos e categorias.

---

## 🚀 Tecnologias Utilizadas

- Java 21
- Spring Boot 3
  - Spring Web
  - Spring Data JPA
- Hibernate
- H2 Database
- Maven

---

## 📚 Conceitos Aplicados

- Arquitetura em camadas
- @Entity
- @Id e @GeneratedValue
- @OneToMany
- @ManyToOne
- @ManyToMany
- Enum persistido
- Tratamento de exceções com @ControllerAdvice

---

## 🏗 Estrutura

- resources
- entities
- repositories
- services
- controllers
- config

---

## ▶ Como Executar

1. Clonar o repositório
2. Rodar a aplicação
3. Acessar H2 Console (se habilitado)
